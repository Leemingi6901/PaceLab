# PaceLab — 마라톤 훈련 AI 분석

공식 대회 기록과 인바디 데이터를 조합해 **현재 체력(VDOT)을 추정**하고, **거리별 예상 PB와 다음 대회의 구간(스플릿) 기록**을 예측하는 개인 훈련 분석 사이트입니다.

## 예측 모델

1. **VDOT 산출** — 각 공식 기록을 Jack Daniels VDOT로 환산
2. **최신성 가중** — 최근 대회일수록 가중치 ↑ (6개월 반감기)
3. **체중 보정** — 인바디 최신 체중으로 상대 VO2max 보정 (±5% 캡)
4. **구간 예측** — 코스 고도(상승 10m당 +9s, 하강 10m당 −4s) + 후반 감속 드리프트(최대 +4%)

## 데이터 입력

`/admin` 페이지에서 인증번호 입력 후 대회 기록·인바디·훈련·예정 대회를 추가합니다.
데이터는 Vercel Blob에 영구 저장되며, 저장 즉시 모든 예측이 갱신됩니다.

> ⚠️ 입력한 데이터는 사이트에 공개 표시됩니다. 인바디 등 민감한 수치는 공개해도 괜찮은 수준만 기록하세요.

## 실행
